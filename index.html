3Why Excel does this & how to avoid it

Excel keeps only 15 significant digits. When you press Enter, every digit after the 15th is replaced with 0 — permanently, so no tool can restore them from the damaged file (re-copy from the original source). Long numbers also turn into 1.42457E+15, and leading zeros vanish.

  • Enter data here first and export the text-safe .xlsx.
  • In Excel, set the column to Text (Home → Number format) before typing or pasting, or type an apostrophe ' before the number.
  • Never double-click a CSV to open it. Use Data → From Text/CSV and set those columns to Text.
  • Don't open and re-save your app-upload CSV in Excel — that is when digits get zeroed.
